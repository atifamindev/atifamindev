### 👨‍💻 About Me

- 📱 **Senior Mobile Developer** focused on Android, iOS, Flutter, and React Native applications.
- 💳 Experienced with **SoftPOS payments, SDK integrations, refunds, voids, secure sessions, PIN login, and biometric authentication**.
- 🧠 Built identity verification flows using **OCR, NFC chip reading, face matching, and liveness checks**.
- 🧩 I care about **clean architecture, maintainable code, performance, and smooth user experience**.
- 🚀 Worked with **Kotlin, Swift, UIKit, Jetpack Compose, Flutter, React Native, ARKit, RealityKit, SceneKit, Agora RTC, Firebase, NestJS, PostgreSQL, and Prisma**.
- 🔍 I enjoy **debugging complex issues, improving app flows, and delivering production-ready products**.
- 💡 My focus is turning requirements into secure, polished, scalable, and real-world mobile solutions.
